# ConsoleCalculator

Консольный калькулятор на Qt 6.12 и C++17. Проект демонстрирует работу сигналов и слотов, обработку ошибок через отдельный сигнал и ведение журнала через отдельный класс Logger.

Поддерживаются операции сложения, вычитания, умножения, деления, сброс, справка и выход. Результаты и ошибки записываются в файл log.txt.

## Сборка
Открыть файл ConsoleCalculator.pro в Qt Creator.
Выбрать установленный комплект Qt 6.12 с MSVC.
Выполнить настройку проекта, если Qt Creator запросит её.
Собрать проект через Build → Build Project.
## Запуск

Запустить программу из Qt Creator или через созданный исполняемый файл.
